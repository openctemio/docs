# OpenCTEM brand

The logo is the Scope symbol (two corner brackets with a marker square caught in the open corner) and the outlined "OpenCTEM" wordmark in Sora 600. The masters live in the product repository (`web/src/assets/brand/` in openctemio/openctem); the files here are copies for the documentation site, the Helm chart icon and outside use.

| File | Use |
|---|---|
| `app-icon.svg` | App icon on the ink tile. The Helm chart icon points to `https://docs.openctem.io/brand/app-icon.svg`: keep this name |
| `avatar.svg` | Square avatar (organization profile picture) |
| `symbol-{light,dark,mono}.svg` | Symbol alone. `light` is for light grounds, `dark` for dark grounds |
| `lockup-{light,dark,mono}.svg` | Horizontal lockup (symbol and name, 6.5:1). `lockup.svg` is the dark one, used by this site |
| `lockup-stacked-{light,dark,mono}.svg` | Stacked lockup (1.8:1) |
| `favicon-16.svg`, `favicon-32.svg` | Dedicated small drawings on whole pixels |
| `og-image.svg` | 1200 x 630 social image |

## Colour

- Brackets and name: ink `#0A1628` on light grounds, paper `#FAFAF9` on dark grounds.
- Marker: teal `#0D9488` on light, `#14B8A6` on dark. It is the only teal element and never touches a bracket or a letter.
- Mono files use `currentColor` for every part.

## Clear space and sizes

- Clear space on every side: one bracket arm (44/104 of the symbol height).
- Minimum: horizontal lockup 16 px tall, stacked 40 px, symbol 16 px. Below 24 px use the 16 px drawing, up to 40 px the 32 px drawing.

## Do and don't

- Do keep the clear space, use the mono files for one-colour printing and the outlined wordmark as drawn.
- Don't move, centre, rotate or recolour the marker, add the other two corners, round the brackets, re-type or re-space the name, or place the logo on photos or mid-tone grounds where ink or paper is under 4.5:1.

The wordmark is set in Sora (SIL Open Font License 1.1, `LICENSE-Sora.txt`) and outlined to paths. The marks are not licensed for use as another product's logo.
